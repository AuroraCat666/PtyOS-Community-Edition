# PtyOS 社区版服务端

基于 .NET 8 的社区服务器，提供 **HTTP 社区服务**（账号/注册/公告/后台）与 **TCP 联机服务**（房间/对战/分数同步）。

## 功能

- 社区账号系统：网页注册（QQ 邮箱验证码）、登录、找回密码、头像
- 邮箱验证码 / 密码找回（SMTP，验证码 60 秒有效）
- 公告系统：发布公告并自动群发邮件给已绑定邮箱的用户
- 管理员控制台：用户管理（封禁/删除）、公告发布、服务器状态
- TCP 联机：登录验证、创建/加入房间、准备、选歌、开始游戏、聊天、实时分数同步
- 谱面上传 / 下载（房主上传 zip，队员下载）

## 目录结构

| 目录 | 说明 |
|------|------|
| `Auth/` | 账号存储（PBKDF2 密码哈希）、token 管理 |
| `Http/` | HTTP 社区服务（HttpListener） |
| `Tcp/` | TCP 联机服务（房间/游戏） |
| `Mail/` | SMTP 邮件服务（MailKit） |
| `Protocol/` | 通信协议模型 |
| `Web/` | 社区前端页面 |
| `data/` | 运行时数据（**不提交到仓库**：账号、密码哈希、谱面等） |

## 部署（Docker）

```bash
docker-compose build rpgr-server
docker-compose up -d --force-recreate rpgr-server
```

数据目录通过 volume 挂载到 `/data`（账号、公告、谱面均持久化，重建容器不丢失）。

### 环境变量

SMTP 密码通过环境变量提供（**请勿硬编码在仓库中**）：

```bash
SMTP_PASS=你的邮箱授权码
```

### 端口

- HTTP：`8080`（社区页面 + API，可经 Caddy 反代 HTTPS）
- TCP：`26377`（联机服务）

## 数据安全

- `data/` 目录包含账号密码哈希、谱面文件等敏感数据，**已被 `.gitignore` 排除，不会上传到仓库**
- SMTP 密码通过环境变量传入，仓库中的 Dockerfile 不包含任何真实凭据

## 主要 API

- `GET /api/userlogin?username=&password=` —— 游戏客户端登录
- `GET /api/userverify?username=&verifytoken=` —— token 验证
- `POST /api/community/register` —— 社区注册（需邮箱验证码）
- `POST /api/community/send-code` —— 发送邮箱验证码
- `POST /api/community/login` / `logout` —— 社区会话
- `POST /api/upload`、`GET /api/download?chartid=` —— 谱面上传/下载
- 更多详见服务端源码 `Http/HttpService.cs`
