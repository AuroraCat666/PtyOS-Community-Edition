# RPGR 社区版 - 项目状态与操作指南

## 一、怎么启动

### 1. 启动服务器（每次用之前都要先开）
双击 `D:\Files\Project\RPGR-Server\启动服务器.bat`
- 看到 "TCP 联机服务已启动" 就说明成功
- 社区页面：浏览器打开 `https://ptyos.yuncishu.xyz/index`
- 关闭：关掉那个黑色窗口

### 2. 启动游戏
- 打开 Unity Hub → 打开 `D:\Files\Project\re-phigros-main` 工程
- 点 Play 运行
